# 📊 Superstore Sales Analysis Dashboard

## 📌 Project Overview

The **Superstore Sales Analysis Dashboard** is an interactive **Power BI data analytics project** developed to analyze sales, quantity, profit, and discount performance.

The dashboard uses interactive visualizations and filters to help users understand business performance across different **categories, sub-categories, regions, months, and years**.

---

## 🎯 Objectives

The main objectives of this project are to:

- Analyze total sales and profit.
- Understand the quantity of products sold.
- Compare sales performance across different sub-categories.
- Analyze product quantity by region and category.
- Track monthly profit trends.
- Compare profit performance across different years.
- Provide meaningful business insights through interactive visualizations.

---

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and visualization
- **Microsoft Excel** – Data source and data preparation
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculations and measures
- **Data Visualization** – Charts, KPIs, and interactive reports

---

## 📌 Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard displays the following key metrics:

- **Total Sales**
- **Total Quantity**
- **Total Profit**
- **Total Discount**

These KPIs provide a quick overview of overall business performance.

### 2. Sales by Sub-Category

A **bar chart** is used to compare total sales across different product sub-categories.

This helps identify the sub-categories that contribute the most to overall sales.

### 3. Quantity by Region

A **donut chart** displays the total quantity of products sold across different regions:

- West
- East
- Central
- South

### 4. Quantity by Category

A **donut chart** represents the quantity of products sold across the following categories:

- Office Supplies
- Furniture
- Technology

### 5. Monthly Profit Analysis

A **line chart** shows total profit by month.

This visualization helps identify:

- Monthly profit trends
- High-profit months
- Low-profit months
- Changes in profitability throughout the year

### 6. Yearly Profit Analysis

A **horizontal bar chart** compares total profit across different years.

This allows users to understand the overall yearly profit performance.

### 7. Interactive Filters

The dashboard includes interactive slicers for:

- **Sub-Category**
- **Region**

Users can select different values to dynamically explore the dashboard and analyze specific parts of the dataset.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the `.pbix` file using **Power BI Desktop**.
3. Make sure the required dataset is available.
4. Refresh the data if required.
5. Use the **Sub-Category** and **Region** slicers.
6. Explore the KPIs and visualizations to analyze business performance.
